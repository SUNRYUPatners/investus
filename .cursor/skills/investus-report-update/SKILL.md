# Investus 리포트 업데이트 스킬

리포트 날짜 세트를 추가할 때 **항상** 이 스킬 + `.claude/commands/report-update.md` 전체 순서를 따른다.

## 문장으로 쓰기 — 제목·부제·본문 (2026-08-25부터 필수)

> 피드백: 제목·부제·본문이 **단어 나열**(티커·숫자·지명·약어를 `·`로 이어 붙이기)이라 초보자가 못 읽는다. 짧게 끊고 끝내지 말고 **문장으로 풀어서, 풍성하게** 쓴다.

**적용 범위:** `title` / `titleEn` / `summary` / `summaryEn` / `subject` / SVG `title`·`heroSub`·카드 `mid`/`sub`·quote·noteSub / `body` 전부. 한장요약 제목도 키워드 체인이 아니라 **한 문장 또는 짧은 문장 2개**.

**금지 (나쁜 예)**
- 제목: `Tesla Cybercab 전용 이벤트 09.03.26 Austin TX · Exclusive Access`
- 요약: `Austin에 4680용 북미 첫 대형 캐소드. 중국 공급 ~90%·2025 수출통제. 건식 코팅.`
- 본문: 숫자 불릿만 나열하고 두세 문단에서 끝. 「왜」를 `1. 허가다. 2. 원가다.`처럼 체언만.

**권장 (좋은 예)**
- 제목: `테슬라가 운전석 없는 전용 로보택시(Cybercab) 공개 행사를 9월 3일 오스틴에서 연다`
- 요약: 2~3문장. 무슨 일 → 그게 뭔지 한 줄 정의 → 왜 오늘 뉴스인지. 예: `테슬라가 운전석을 없앤 전용 로보택시 사이버캡 행사를 2026년 9월 3일 텍사스 오스틴에서 연다고 알렸다. 기존 모델Y에 소프트웨어만 얹은 차가 아니라, 처음부터 무인 운행용으로 만든 차량이다. 날짜가 박히면 상용 일정이 말에서 캘린더로 내려온 것이다.`
- 본문: 아래 「풍성함」 기준.

**제목·부제 규칙**
- 주어+동사가 있는 **한글 문장**. 영문 제목도 마찬가지로 문장(또는 완전한 절). 티커는 필요하면 앞에 `테슬라(TSLA)`처럼 한 번만.
- `·`로 고유명사·숫자를 5개 이상 나열하지 말 것. 꼭 넣을 숫자는 문장 속에 (`약 87%`, `981억 달러`).
- `subject`(카드 작은 라벨)만 짧게 허용. 제목/요약을 subject처럼 쓰지 말 것.
- SVG `heroSub`도 헤드라인 조각이 아니라 **2문장 안팎의 설명**.

**본문 풍성함 (짧게 쓰고 끝내지 말 것)**
- 분량 기준은 여전히 **2026-08-18 seed-994급**이되, 그 안을 **설명 문단**으로 채운다. 섹션당 불릿 5개로 때우지 말 것.
- 초보 독자를 가정한다. 처음 나오는 용어마다 **한 문장 정의**(캐소드=배터리 양극재, ARR=1년으로 환산한 구독·계약 매출, IRR=투자금 대비 연율 수익률, Supervised=사람이 감독하는 자율주행).
- `■ 상세`는 사건 재진술 한 덩어리로 끝내지 말고, **배경(왜 이 숫자가 나오나)** · **비교(예전/경쟁/다른 해석)** · **한계(아직 모르는 것)** 를 문단으로 이어 쓴다.
- `■ 왜 이 뉴스가 중요한가`는 번호가 있어도 **각 번호가 2~4문장**. 한 줄 구호 금지.
- 시나리오·반대·앞으로 볼 것도 **문장**. `- 수율 안정` 같은 메모형 금지. `수율이 안정되면 북미에서 셀을 더 싸게 뽑을 수 있어, 로보택시 대당 원가 논쟁이 누그러질 수 있다.`처럼.
- `■ 투자시사점`은 사실 반복이 아니라, 초보가 **그래서 무엇을 추적하면 되는지**를 3문단 이상으로 풀어 쓴다.

**자가 점검 (배포 전)**
- 제목을 소리 내어 읽었을 때 쉼표 없이 고유명사만 이어지나? → 다시 문장으로.
- 요약을 주식 처음 보는 사람한테 줬을 때 약어를 설명 없이 쓰는가? → 풀이 추가.
- body가 스크롤 한 화면에 다 들어오나? → 대개 너무 짧다. 상세·왜·시나리오를 문단으로 보강.

### SVG 카피 밀도 — 초보자도 이미지만으로 이해 (2026-08-22부터 · **다음날 생성분부터 적용**)

> 반려/피드백: 인용 박스 1문장 + 「왜 중요한가」 2줄만 있으면 처음 보는 사람이 용어·의미를 못 잡음 (예: Cybercab / 유닛 이코노믹스 / NTA 발언만 단정).

**중간 인용(quote) 박스**
- 단순 헤드라인 복붙 금지. **무슨 일이 있었는지 + 어디서/누가 + 숫자·범위 1개**를 2~4줄로.
- 전문 용어가 나오면 바로 옆에 짧은 풀이 한 절 (예: 「Cybercab = 운전석 없는 전용 로보택시 차량」).
- KO 기준 대략 **80~140자 / 2~4줄**을 목표. 한 줄짜리 인용만 두지 말 것.

**하단 「왜 중요한가」/ noteHead·noteSub (또는 의미 박스)**
- noteHead만 쓰지 말고 **noteSub에 초보용 설명 2~3문장**을 반드시 채운다.
- 구조 권장: (1) 이게 왜 뉴스인가 한 줄 → (2) 기존과 뭐가 다른지 / 비교 대상 → (3) 다음에 볼 포인트 한 줄.
- 전문 용어(유닛 이코노믹스, 허가, lockup, D2D 등)는 **비유·한 줄 정의**로 풀기.
- KO 기준 noteSub **약 100~180자 / 2~3줄** — 카드 3개에 이미 쓴 키워드만 반복하지 말 것.

**KPI/피처 카드 3칸**
- `big`은 짧아도 됨. `mid`·`sub`에는 **초보가 맥락 잡는 보조 설명**을 넣기 (지명·기간·비교 대상).

**레이아웃 여유**
- 글이 늘면 quote/note 박스 높이·`multilineIfOverflow` maxLines를 **먼저 늘리고** 잘라내지 말 것 (잘림·빈공간 체크는 PNG로).
- 「투자 시사점」 라벨은 여전히 SVG에 금지 — 설명은 자연 문장으로만.

**소재별 레이아웃 매칭 가이드:**
- 지표 1개가 핵심 → 레이아웃 1 (숫자 히어로 + KPI 2개)
- 지표 3개 이상(실적 발표, 생산 스케일업 등) → 레이아웃 2 (3-스탯 카드)
- 인물 발언/코멘트가 핵심(버핏, 젠슨 황 등) → 레이아웃 4 (인용박스+칩) 또는 배지+문구 히어로
- 기능 출시·마일스톤 완주 → 레이아웃 3 (체크마크+피처카드)
- A vs B 대비가 핵심(가격 인하폭 비교, 설문 응답 비교, IPO가 대비 현재가 등) → 레이아웃 5 (Before→After 화살표)
- 순위/1위 발표·전월 대비 급등 등 임팩트 큰 뉴스 → 레이아웃 6 (BREAKING 배지 + 큰 히어로)

**작업 순서:**
1. 오늘 다룰 소재 16개(또는 해당 개수)를 확인하고, 각 소재를 위 매칭 가이드로 레이아웃 1~6에 분배한다 (하나의 레이아웃이 전체의 40%를 넘지 않게)
2. 레이아웃별로 해당하는 7/2 파일을 Read로 열어 정확한 구조·좌표를 확인한다
3. 그 구조를 그대로 이번 소재 데이터로 채워서 생성 — "핵심사실/투자시사점" 2단 카드나 배경 그리드는 넣지 않음
4. 완성 후 sharp로 PNG 렌더링해서 실제로 눈으로 확인 (잘림/오버플로/이모지 깨짐/레이아웃 겹침 체크)
5. **이모지 주의**: `scripts/export-report-pngs.js`의 `stripEmoji()`가 `\u{1F000}-\u{1FFFF}`, `\u{2600}-\u{27BF}`, `\u{FE00}-\u{FE0F}` 범위만 제거한다. 이 범위 밖 이모지(예: ⏳ U+23F3)는 stripped되지 않고 깨진 fallback 글리프(검은 박스)로 렌더링되니 반드시 위 범위 안의 이모지만 사용할 것.

## 본문(body) 원칙

1. **본문(`lib/reports.ts` body/bodyEn)에는 상세 설명·배경·출처·투자시사점을 충분히 채운다.** 분량은 **2026-08-18 리포트(seed-994 등) 수준의 한글 서술**을 기준으로 한다 — 짧게 끊은 영문 불릿 아웃라인 금지. **2026-08-25부터는 그 분량을 ‘키워드 압축’이 아니라 초보용 문장으로 채운다** (위 「문장으로 쓰기」).
2. 권장 구조(한글 **완결 문장**): `■ 상세` → `■ 왜 이 뉴스가 중요한가` → (시나리오/경쟁 구도) → `■ 오늘까지 흐름` → `■ 반대 관점` → `■ 앞으로 볼 것` → `■ 투자시사점`. 의미·향후 전망·시나리오를 서술로 풀어쓴다.
3. **금지**: `■ 배경 / 관련 보도 (상세)` 아래 영문 메모형 불릿(`Exact prints…`, `Align with…` 등). 관련 보도는 한글 문장 속에 출처를 녹여 쓴다. **제목·요약을 `A · B · C` 헤드라인 체인으로 쓰는 것도 금지.**
4. 모든 개별 리포트에 `■ 투자시사점` (EN: `■ Investment Implications` 또는 Aug 18처럼 `bodyEn: "See Korean body.…"`) 필수 — SVG 안에는 라벨 없이 자연스럽게 녹여도, 본문에는 항상 명시적 섹션으로 있어야 함.
