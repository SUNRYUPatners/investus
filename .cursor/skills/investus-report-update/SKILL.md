# Investus 리포트 업데이트 스킬

리포트 날짜 세트를 추가할 때 **항상** 이 스킬 + `.claude/commands/report-update.md` 전체 순서를 따른다.

## 에이전트 — 리포트 업데이트는 Auto (2026-09-02~)

리포트 업데이트(`리포트 업데이트`, `report-update`, 일일 seed·SVG·본문 배치)는 **부모 에이전트(Auto 기본 라우팅)가 직접** 끝까지 수행한다.

- **금지:** Task 서브에이전트에 **`claude-opus-5-thinking-high`(Opus 5) 등 모델을 지정**해 위임하는 것. 리포트 업데이트용 Opus 강제 규칙은 **폐지**.
- **허용:** 분량이 커도 부모가 직접 처리. 정말 위임이 필요하면 Task 서브에이전트에 **`model` 없이(inherit/Auto)** 전체 체크리스트를 넘긴다.
- **완료 기준:** `validate-*` 통과 + `bash scripts/deploy.sh` 성공 로그 확인 전 “완료” 금지 (모델과 무관).

## 문장으로 쓰기 · 존댓말 — 제목·부제·본문 (2026-08-25부터 필수)

> 피드백 1: 제목·부제·본문이 **단어 나열**이라 초보자가 못 읽는다. 문장으로 풀어서 풍성하게 쓴다.
> 피드백 2: 리포트 말투가 **반말**이다. 공식 리포트는 **존댓말(합니다체)** 로 쓴다.

**적용 범위 (존댓말 + 문장):** `title` / `summary` / `body` / SVG 한글(`title`·`heroSub`·quote·noteSub·카드 설명) / 한장요약 제목·요약. 영문(`titleEn` 등)은 평서문 문장.

**출처 이름은 쓰지 않습니다 (2026-08-25~)**
- 독자에게는 **내용만** 씁니다. 스크린샷·소셜 핸들·매체 바이라인은 카피에 넣지 않습니다.
- **금지 예:** `Cosmos Europa`, `DogeDesigner`, `Robotaxi Radar`, `Doctor Jack`, `Shay Boloor`, `Joe Hansen`, `Sam Badawi`, `Evan`, `Sawyer Merritt`, `Barchart`, `Bull Theory`, `(출처 Company reports, Deutsche Bank Research)` 를 heroSub·카드 `sub`·quote·본문 첫머리에 반복.
- 나쁜 예: `Cosmos Europa: F14가 F13보다 어렵다` / 카드 하단 `Cosmos Europa` / `"Cosmos Europa는 Flight 14가 13보다 어렵다고 했다."`
- 좋은 예: `스타십 14번째 비행은 13번째보다 어렵습니다. 41호기는 초속 약 7.8km로 궤도에 들어간 뒤 한 바퀴를 돌고 다시 대기권으로 들어오며, 연료를 남깁니다.`
- **예외:** 그 매체·인물의 발언 자체가 뉴스인 경우만 (예: 워런 버핏 인터뷰, 머스크 본인 발언). 그래도 같은 이름을 제목·카드·인용에 세 번 반복하지 말고, 카드 `sub`에 출처 라벨을 달지 않습니다.
- 팩트체크는 내부에서 스크린샷과 숫자를 대조합니다. 출처를 지웠다고 숫자를 지어내지 않습니다.

**예외 — 반말·구어체 유지:** `lib/wallPosts.ts` 종토방만. 익명 게시판 캐릭터이므로 구어체를 유지한다. 애널리스트 글(`analystPosts.ts`)도 공식 해설에 가깝게 **존댓말**로 쓴다 (캐주얼 이모티콘·반말 금지. 구조 다양화 규칙은 유지). 애널도 계정명 나열은 하지 않고 내용만 씁니다.

**한글판 애널 — 영문 키워드 나열 금지 (2026-08-27)**
- 나쁜 예: `Terafab Texas +$48B, total $119B… build window입니다.` / `today bundle: NVDA beat/AH -2%…`
- 좋은 예: `텍사스 테라팹 추가 투자 480억 달러가 더해지며 총 규모가 약 1,190억 달러로 잡혔습니다.`
- 영문 `titleEn`/`bodyEn`이 필요한 리포트와 달리, **한글 UI 애널 카드(`content`)는 한국어 문장**이 본문이다.

**말투 (합니다체)**
- 종결: `~습니다` / `~입니다` / `~합니다` / `~했습니다` / `~됩니다`. 인용문 속 원문만 반말 허용.
- **금지:** `~다` / `~이다` / `~한다` / `~인가` / `~봐야지` / `~임` / `~네` 등 반말·음슴체·체언 종결.
- 제목도 가능하면 합니다체. 너무 길면 `~합니다`로 끝나는 한 문장. 예: `테슬라가 … 행사를 엽니다`

**금지 (나쁜 예)**
- 제목: `Tesla Cybercab 전용 이벤트 09.03.26 Austin TX · Exclusive Access`
- 반말: `테슬라가 오스틴에서 사이버캡 행사를 연다`
- 요약: `Austin에 4680용 북미 첫 대형 캐소드. 중국 공급 ~90%·2025 수출통제.`
- 본문: `1. 허가다. 2. 원가다.` / `수율 안정`

**권장 (좋은 예)**
- 제목: `테슬라가 운전석 없는 전용 로보택시(사이버캡) 공개 행사를 9월 3일 오스틴에서 엽니다`
- 요약: `테슬라가 운전석을 없앤 전용 로보택시 사이버캡 행사를 2026년 9월 3일 텍사스 오스틴에서 연다고 알렸습니다. 기존 모델Y에 소프트웨어만 얹은 차가 아니라, 처음부터 무인 운행용으로 만든 차량입니다. 날짜가 정해지면 상용 일정이 말에서 달력으로 내려온 것입니다.`
- 시나리오 한 줄: `수율이 안정되면 북미에서 배터리 셀을 더 싸게 만들 수 있어, 로보택시 한 대 원가 논쟁이 누그러질 수 있습니다.`

**제목·부제 규칙**
- 주어+동사가 있는 **한글 존댓말 문장**. 영문 제목도 완전한 절. 티커는 필요하면 `테슬라(TSLA)`처럼 한 번만.
- `·`로 고유명사·숫자를 5개 이상 나열하지 말 것. 숫자는 문장 속에 (`약 87%`, `981억 달러`).
- `subject`(카드 작은 라벨): 관용 한글명이 있으면 그걸로 (`테슬라`, `스페이스X`, `엔비디아`). **관용 한글 음역이 어색한 티커·기업은 영어 그대로** (`ASML`, `TSMC`, `Nebius`). `Citizens IRR` 같은 토픽 슬러그 금지. 특집은 `한장요약`, 매크로는 `금리` 등 짧은 분류.
- SVG `heroSub`는 **2문장 안팎, 합니다체**.

**⚠️ 기업명·약어는 영어 유지 (2026-09-09 피드백 · 다음날부터 필수)**

> 「영어를 아예 쓰지 말라」가 **아닙니다.** 금지하는 것은 `supply fear` · `capex ramp` 같은 **영문 키워드 덤프**뿐입니다.

- **영어 그대로 쓰기:** 상장 티커·공식 기업명(`ASML`, `TSMC`, `NVIDIA`/`엔비디아` 병기 OK), 기술 약어(`4K`, `EUV`, `FSD`, `HBM`, `GPU`), 제품·모델 코드.
- **금지:** 억지 한글 음역 — `에이아스엠엘`/`에이에스엠엘`(→ `ASML`), `티에스엠씨`(→ `TSMC`), `4케이`(→ `4K`), `엔비스`(→ `Nebius` 또는 `NBIS`).
- **관용 한글은 유지:** `테슬라`, `엔비디아`, `비트코인`, `구글`처럼 이미 읽히는 이름은 한글 가능. 헷갈리면 `엔비디아(NVDA)`처럼 **한글+티커 한 번**.
- 적용: `title`/`summary`/`body`/SVG 한글판/애널·종토방. 배포 전 음역 grep (`에이아스|티에스엠|4케이` 등) 권장.

**본문 풍성함 (2026-09-09 리셋 · 이해 우선)**
- 분량보다 **초보가 이해되는지**가 우선. 「오늘 무슨 일?」에 한 문장으로 답할 수 있어야 한다.
- `■ 무슨 일인가요` — 스크린샷·뉴스를 존댓말 문단으로 풀기. 용어마다 한 줄 정의.
- `■ 조금만 더 알려드리면` — 짧으면 웹 검색으로 배경·관련 뉴스 2~4문단 보충.
- `■ 장기적으로 보면` — 3~5년 긍정 뷰를 **쉬운 한글**로 (템플릿 해자 문장 금지).
- `■ 투자 시사점` — 무엇을 표에 둘지 2~3문단. 매수/매도 단정 금지.

**자가 점검 (배포 전)**
- 제목이 고유명사 나열인가? → 문장으로.
- 한글 본문에 `다.` / `이다.` / `한다.` / `임.` 으로 끝나나? → 합니다체로.
- **본문을 읽고 「무슨 일 / 왜 / 뭘 보면 되나」에 답할 수 있는가?** → 아니면 다시 씀.
- **한글 `title`/`summary`/`body`에 영문 키워드 덤프가 섞였는가?** → 한국어 문장으로. 단 **기업명·약어(ASML, 4K 등)는 영어 유지.** 배포 전 `node scripts/validate-report-korean.js` 통과 필수.
- 억지 음역(`에이아스엠엘`, `4케이`)이 남아 있는가? → 영어 원문으로.
- 카드·인용·hero에 소셜/매체 출처 이름이 보이나? → 지우고 내용만.
- 약어를 설명 없이 쓰는가? → 풀이 추가.
- `히어로 숫자`·`실측/계획/의견 세 칸` 같은 **공통 템플릿 문장**이 여러 seed에 반복되는가? → 전부 소재별 문장으로 교체.

### 본문 섹션 — **초보가 이해되는 글** (2026-09-09 전면 리셋 · **다음날 리포트부터 필수**)

> **사고:** `■ 상세` · `왜 이 뉴스가 중요한가` · `시나리오` · `오늘까지 흐름` · `장기 투자 관점` · `앞으로 볼 것` · `투자시사점`을 채워도 **무슨 말을 하려는지 모른다**. 원인 = 템플릿 문장 복붙(`히어로 숫자`·`실측/의견/계획`·`해자` 반복) + 스크린샷을 풀지 않음.
>
> **목표:** 투자 초보가 **한 번 읽고** 「오늘 무슨 일이 있었고, 왜 관심 가질 만하며, 앞으로 뭘 보면 되는지」를 말할 수 있어야 한다.

#### 새 필수 구조 (개별 리포트 · 2026-09-10~)

```
■ 무슨 일인가요        ← 필수. 스크린샷·뉴스를 초보 말로 풀이
■ 조금만 더 알려드리면  ← 필수. 짧으면 웹 검색으로 배경·관련 뉴스 보충
■ 장기적으로 보면      ← 필수. 긍정 톤의 3~5년 뷰 (검색·맥락으로 뒷받침)
■ 투자 시사점          ← 필수. 초보가 「그래서 뭘 보면 되나」
```

한장요약은 `■ 오늘의 큰 그림` + `■ 투자 시사점` (필요 시 `■ 앞으로 볼 것` 한 줄 리스트만).

#### 구 섹션 폐기 (의무 금지)

다음 제목을 **의무로 두지 않습니다.** 쓰더라도 템플릿 문장만 채우면 **반려**.
- ~~`■ 상세`~~ → `■ 무슨 일인가요`로 대체
- ~~`■ 왜 이 뉴스가 중요한가`~~ (번호 1~5 템플릿) → `무슨 일`·`조금만 더` 안에 자연스럽게
- ~~`■ 시나리오`~~ 가/나/다 템플릿
- ~~`■ 오늘까지 흐름`~~ 한 줄 키워드
- ~~`■ 앞으로 볼 것`~~ `(1)…(5)…` 복붙 — 구체 일정이 있을 때만 `조금만 더` 또는 `투자 시사점`에 녹임

#### 섹션별 쓰는 법

| 섹션 | 해야 할 일 | 금지 |
|------|------------|------|
| **무슨 일인가요** | 스크린샷(또는 검색 뉴스)의 **사실**을 문단으로 풀기. 용어는 바로 옆에 한 줄 정의. 「누가 / 무엇을 / 숫자 / 왜 화제인지」가 보이게. | 키워드 나열, 템플릿 첫 문장만, 출처 핸들 |
| **조금만 더 알려드리면** | 스크린샷만으로 짧으면 **웹 검색**으로 배경·경쟁·일정·관련 보도를 **2~4문단** 보충. 초보가 맥락을 잡게. | 스크린샷에 없는 숫자를 지어내기 · 영문 키워드 덤프 |
| **장기적으로 보면** | 「이 산업·회사가 **지금까지** 어떻게 왔고, **앞으로 몇 년** 왜 긍정적일 수 있는지」를 **쉬운 한글**로. 가능하면 검색한 추세·해자·수요를 문장에 녹임. | `해자`만 반복 · `하루짜리가 아니라 수년짜리` 복붙 · 반대 관점 번호 리스트 |
| **투자 시사점** | 「초보 투자자가 **표에 적어 둘 것**」을 2~3문단. 예: 요금·대기, 승인 나라 수, 실적 발표일. | 매수/매도 단정 · 레버리지 권유 · `실측/계획/의견 세 칸` 복붙 |

4. **닉네임 `종토_90xx`** — 자동 생성 느낌. 캐릭터 닉네임(칠천피존버, 반도체장기 등) 사용.
5. **리포트 숫자와 불일치** — 종토방·애널의 %·가격·수급은 **당일 리포트 팩트**와 맞출 것 (예: 삼전 +1.8% not +0.82%).
6. **교차시장 문구 금지 (2026-09-04 사고)** — 미국 종토방/애널에 `종부세`·`케이비`·`엘지엔솔`·`코스피` 수급 금지. Safe에 종부세 금지. KR-RE에 비트코인·허깅페이스 금지. **시장별 댓글 풀을 따로** 쓰고, 티커만 바꿔 돌리는 배열 금지.
7. **동일 오프닝·종결 템플릿 금지** — `숫자만 남기면…레버리지는 내일`, `나는 허가랑 공시부터`, `○○ 확인했습니다. 숫자부터 표에`, `다음 확인 지표는 ○○ 쪽에서`, 애널 `종목명 N원(+X%). …하시기 바랍니다`를 하루치 절반 이상에 반복 금지. **글마다 구조(Q&A·회의·숫자먼저·현장감·짧은 스탠스)를 섞을 것.**
8. **애널 자동 템플릿 생성 금지 (2026-09-07 사고)** — `apply-*.js`에서 summary 앞에 `만 보면 놓칩니다` / `왜 ○○인가요?` / `○○ 축:` / `한장입니다.`를 붙이거나, 댓글에 `한국 N번째 리포트`·`안전자산 N:`·`부동산 N:`처럼 **번호만 바꾼 동일 문장**을 넣지 말 것. 동일 문장+번호는 validate를 우회해도 **피드에서는 복붙**으로 보인다. KR/Safe/KR-RE 애널은 **글마다 다른 오프닝·다른 댓글**을 수동 또는 `rewrite-analyst-markets-*-diverse.js`로만 작성. `validate-analyst-mock-sync.js`가 오프닝·번호템플릿 댓글을 배포 차단한다.
9. **애널 댓글 ↔ 글 주제 1:1 (2026-09-08 사고)** — `MOCK_ANALYST_COMMENTS`는 **같은 id의 글 symbol·본문 주제**에만 맞춰 쓴다. 고유 댓글 배열을 index로 밀어 넣으면 NVDA 글에 사이버캡·TSLA 글에 파이어버드가 붙는다. **일괄 rewrite 시 ID 오프셋 금지** — 글마다 `[-id]:`를 열어 주제를 확인한 뒤 댓글을 작성. `validate-analyst-mock-sync.js`의 심볼 교차 키워드 검사가 배포를 차단한다.

## 스크린샷 → 리포트 전량 반영 (2026-09-02 · **필수**)

> **사고:** 스크린샷에 중국 FSD V14 내부시험(Tsla Chan)이 있었는데, `topics-20260902-data.js`가 **상위 15개만** 골라 `seed-1460`이 빠짐. 같은 티커(FSD)라도 **미국 Cybercab 45대**와 **중국 V14 직원시험**은 완전히 다른 스토리.

### 절대 금지

1. **「상위 15개」「핵심만」「대표 토픽」으로 스크린샷을 걸러내기** — 스크린샷·이미지에 보이는 **주제마다** seed 1개(또는 합칠 때 이유 명시).
2. **같은 티커·같은 테마 = 하나로 합치기** — 예: US 로보택시 ≠ 중국 FSD V14 내부시험. 각각 별도 리포트.
3. **미확인 보도를 공식 공시처럼 쓰기** — 팩트체크 후 라벨: `공시 확인` / `언론 보도` / `루머·내부시험(미확인)` 을 본문·요약에 명시.

### 스크린샷 N장 → seed N개 체크리스트 (배포 전 필수)

작업 시작 시 채팅·노트에 아래 표를 만들고, **끝날 때까지 100% 채운 뒤** 배포한다.

| # | 스크린샷·이미지 (한 줄 설명) | seed id | SVG ko/en | 합침 여부·이유 |
|---|------------------------------|---------|-----------|----------------|
| 1 | (예: Cybercab 9/3 Austin) | seed-1445 | ✓ | — |
| 2 | (예: 중국 FSD V14 직원시험) | seed-1460 | ✓ | US Cybercab과 별개 |
| … | … | … | … | … |

- **행 수 = 반영한 주제 수.** 스크린샷에 20개 주제면 표에 20행(+ 한장요약은 별도).
- **합침**은 예외만: 동일 팩트·동일 각도가 2장에 중복일 때만. 이유 칸에 `동일 Cybercab D-1 포스터 2장`처럼 적기.
- **빈 칸이 있으면 배포 금지.**

### 팩트체크 · 공시 vs 루머

1. 스크린샷 내용을 **웹 검색·공시 DB**로 대조.
2. **확인된 공시** → 본문에 사실 서술, 날짜·수치 정확히.
3. **언론·소셜만** → `아직 공식 확인 전` / `보도에 따르면` 등.
4. **내부시험·루머** → `미확인`, `내부 직원 대상 시험으로 알려졌으나 테슬라 공식 발표는 없음` 등 **투자 리스크**를 분명히.
5. 출처 **이름**은 SKILL 상단 규칙대로 카피에 넣지 않음. 팩트만.

### 워크플로

1. 관리자 스크린샷·이미지 **전부** 나열 → 위 체크리스트 표 작성.
2. 주제마다 `scripts/topics-YYYYMMDD-data.js`에 `add()` — **개수 제한 없음**.
3. `node scripts/gen-reports-YYYYMMDD.js` → `lib/reports.ts` 삽입 → wall·analyst 연동.
4. 체크리스트의 seed·SVG 열 전부 ✓ 확인 후 `validate-report-assets.js` 등 통과.
5. `bash scripts/deploy.sh`.
